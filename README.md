# wowfarsi-suggestions

صندوق بررسی پیشنهادهای ترجمهٔ [wowfarsi.ir](https://wowfarsi.ir).

هر پیشنهاد یک Issue است که از تب «کمک به ترجمه» در اتاق کاستوم سایت پیش از پر شده می‌آید.

## وضعیت هر پیشنهاد

- **باز** = منتظر بررسی
- **بسته به عنوان completed** = قبول شد، در همه‌جای سایت اعمال می‌شود
- **بسته به عنوان not planned** = رد شد

متن هر Issue یک کامنت مخفی `<!-- wf-suggestion {...} -->` دارد که ابزار اعمال پیشنهادها آن را می‌خواند. لطفاً این خط را ویرایش نکنید.

Suggestions for the Persian translation of wowfarsi.ir. Each suggestion is an Issue pre-filled by the site; close as completed = accepted, not planned = rejected.
